# Gestion de Restaurant Microservices

## Introduction
Ce projet vise à développer une solution complète pour la gestion des restaurants en utilisant une architecture microservices. Chaque composant de l'application est autonome et peut être développé, déployé et scalé indépendamment.

## Fonctionnalités
- **Gestion des Réservations** : Permet aux clients de réserver une table en ligne.
- **Gestion des Commandes** : Suivi et traitement des commandes des clients.
- **Gestion des Menus** : Ajouter, modifier ou supprimer des plats.
- **Gestion des Paiements** : Traitement sécurisé des paiements en ligne.

## Technologies utilisées
- Node.js
- Express
- MongoDB
- Docker
- Kubernetes

## Installation
1. Clonez le repository.
2. Installez les dépendances avec `npm install`.
3. Configurez les fichiers d'environnement.
4. Lancez les microservices avec Docker.
